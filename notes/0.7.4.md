Kind: feature

- **Tabs.** Open as many files as you like, each in its own tab with its own unsaved changes, undo and place in the file. A file the canvas points at opens in an italic preview tab that the next one replaces until you edit it or double-click it. Closing a tab with unsaved changes asks Save, Don't save or Cancel. Middle-click closes, drag reorders, and the tabs come back after a restart.
- **Go to definition.** F12, ⌘-click or the right-click menu opens where a function, class or import is defined, in a new tab at that line. Several places give a short list; none says so.
- **Find, and search the whole project.** ⌘F finds in the file with match case, whole word and regular expressions, "3 of 12", and Replace / Replace all. ⇧⌘F searches every file of the project, skipping what git ignores; a result opens at its line.
- **Everything from the keyboard.** ⇧⌘P lists every command with its key, ⌘P goes to a file, ⇧⌘O and ⌘T go to a symbol, ⌃G to a line. Change any key in Keyboard shortcuts (JSON), VS Code's format; a mistake is pointed out by line and skipped.
- **Drop a file to open it.** Drag a file from another module onto the Editor and it opens in a tab.

## For agents

- New door tools: `open_files` (one or more files as tabs, at a line or range, in the background unless `focus` and the active tab is unedited; held until the Editor opens when no page is open), `tabs`, `focus_tab`, `close_tabs` (saved tabs only; an unsaved one is named and kept), and `commands` (every command with its keys). The door still never writes a file.
