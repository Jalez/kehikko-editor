- **Edit the file the canvas points at.** Editor opens the same file Source shows, follows the canvas as it moves, and lets you open another from its Go menu.
- **You decide when to save.** There is no autosave: Save, ⌘S or the header's Save writes the file.
- **Your work and the disk never clash silently.** If the file changed on disk since you started editing, Editor refuses to overwrite it and offers to reload or compare.
- **Kehikot's own files stay safe.** Files under `.kehikot/` open read-only, and very large or binary files are not opened.
