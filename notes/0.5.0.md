- **The file and whether it is saved, in the footer.** In a Kehikot that draws module footers, the Editor says along the bottom edge of its container which file is open, whether it is saved, unsaved or changed on disk, whether it is read-only or private, and its language, so a container folded to its header and footer still says it.
- **The code gets the room.** With that footer, the bar along the top of the page is gone (Save is in the header), and the one-line notes under it (why a file is read-only, what just happened, what went wrong) are said in the footer.
