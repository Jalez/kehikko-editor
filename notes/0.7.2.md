Kind: feature

- **Says who keeps a document.** A file of a document that takes changes only as proposals now opens read-only with the name of the module that keeps it, and tells you to suggest your change there.
- **Follows a document wherever its folder leads.** When a document's folder is a link to a folder elsewhere in your project, the files there are read-only here too, as long as the module that keeps it is running.
