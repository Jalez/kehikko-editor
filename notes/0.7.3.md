Kind: feature

- **Says whose a file under `.kehikot/` is, in the owner's own words.** A file a module keeps opens read-only with the name that module declares for its folder and what it keeps there. A folder no module in use declares is still read-only, in generic words.

## For agents

- The owner of each `.kehikot/` folder is read from the `module.folders` service (protocol 2.85.0) through the host; Editor keeps no list of module names. Editor owns no folder under `.kehikot/`, so it declares none.
